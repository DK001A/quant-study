\# A股交易规则 Checklist



| 规则 | 依据 (或说明) | 数据字段 | 验收用例 / 备注 |

| :--- | :--- | :--- | :--- |

| \*\*主板涨跌幅 ±10%\*\* | 正常交易日涨跌幅限制 | 最高/最低价 | `close` 相对前收的涨跌幅不能超过10% |

| \*\*ST / \*ST ±5%\*\* | 风险警示板股票 | 股票名称(带ST) | 名称中包含 `ST` 或 `\*ST` 的股票 |

| \*\*创业板/科创板 ±20%\*\* | 300开头(创业) / 688开头(科创) | 股票代码 | 代码以 `300` 或 `688` 开头 |

| \*\*北交所 ±30%\*\* | 8开头(北交所) | 股票代码 | 代码以 `8` 开头 |

| \*\*新股上市前5日不设限\*\* | 注册制新股规则 | 上市日期 | 上市前5个交易日无涨跌幅限制 |

| \*\*T+1 交收\*\* | 当天买入，次日才能卖出 | 交易日期 | 回测时持仓期至少为1天 |

| \*\*最小交易单位 100 股\*\* | 1手 = 100股 | 成交量 / 股数 | 买入数量必须是100的整数倍 |

| \*\*停牌不可交易\*\* | 价格无波动，无成交量 | 成交量 | 当日成交量为 0 或为空 |

| \*\*退市整理期\*\* | 涨跌幅限制为 10% | 股票名称 | 名称中包含退市字样 |

| \*\*涨停价计算公式\*\* | 前收 × (1 + 比例) 四舍五入到分 | 昨收(close) | 例如昨收10元，主板涨停价 = 10 \* 1.1 = 11.00元 |



> \*\*注意：\*\* 涨停判定不能简单用 `pct\_change > 0.095`，必须严格按四舍五入计算，因为有些股票前收价格尾数会导致涨跌幅不是整10%。
